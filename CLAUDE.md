# wp-headless2static

A monorepo boilerplate that uses WordPress as a headless CMS and Astro as the frontend to build static sites.

Design spec: `docs/superpowers/specs/2026-08-13-wp-headless2static-design.md`

## Commit Convention

- Write commit messages in **English**
- Follow **Conventional Commits**: `<type>(<scope>): <description>`
  - type: `feat` / `fix` / `docs` / `chore` / `refactor` / `test` / `ci` / `build`
  - scope is optional; prefer the monorepo package name (e.g. `feat(wp-client): add retry with backoff`)
- Description: lowercase, imperative mood, no trailing period

## Documentation Language

- `CLAUDE.md` is written in English only
